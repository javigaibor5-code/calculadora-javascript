# 🧮 Calculadora Básica

Primer proyecto de mi portafolio como estudiante de Tecnología en Desarrollo de Software.
Una calculadora funcional construida con **HTML, CSS y JavaScript puro** (sin frameworks ni librerías).

## 🔗 Demo
[Ver proyecto en vivo](#) <!-- Reemplaza con tu link de GitHub Pages -->

## ✨ Funcionalidades
- Operaciones básicas: suma, resta, multiplicación y división
- Cálculo de porcentajes
- Borrado de un solo dígito o de todo el valor
- Soporte de teclado físico (números, operadores, Enter, Backspace, Escape)
- Manejo de errores (ej. división entre cero)

## 🛠️ Tecnologías
- HTML5
- CSS3 (Grid, variables CSS)
- JavaScript (manipulación del DOM, eventos)

## 📚 Qué aprendí
- Manejo del DOM y eventos de `click` y `keydown`
- Manejo de estado simple en JavaScript (valor actual, valor anterior, operador)
- Diseño de interfaz con CSS Grid y buenas prácticas de accesibilidad visual

## 🚀 Cómo ejecutarlo localmente
1. Clona este repositorio
2. Abre el archivo `index.html` en tu navegador (no requiere instalación ni dependencias)
